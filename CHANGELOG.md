# Changelog

## 0.1.0 — 2026-09-10

Initial open-source version.

- Local Ollama embeddings and generation with persistent Chroma storage.
- JSON CLI for ingestion, querying, inspection, deletion synchronization, environment checks, and experiment runs.
- Recoverable synchronization with source-root binding, strict scans, an operation journal, and filesystem locking.
- Three fictional-document trials with 69 recorded generation requests and a separate 443-check evidence audit.
- 37 deterministic tests covering lifecycle, failures, process restart, and evaluation behavior.
- MIT licensing, reproducibility documentation, community guidance, and Linux/macOS CI.

The published reference evidence redacts personal paths and the test hostname. New local runs, raw logs, and index workspaces are excluded from Git. Native Windows is not supported; use WSL.
