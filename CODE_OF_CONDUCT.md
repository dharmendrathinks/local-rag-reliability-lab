# Code of conduct

We want this project to be a useful place to learn, reproduce findings, and disagree about evidence. Everyone participating in issues, pull requests, and other project spaces is expected to:

- Treat others respectfully regardless of background, identity, or experience.
- Critique claims and code with specific evidence; accept corrections in good faith.
- Respect privacy and ask before sharing someone else's personal information.
- Avoid harassment, threats, discriminatory language, sexual attention, spam, and personal attacks.

The maintainer, [Dharmendra Thinks](https://github.com/dharmendrathinks), may edit or remove content, close or lock conversations, and restrict participation. Responses may range from a warning to a permanent ban, depending on severity and repetition. These expectations also apply to maintainers.

Report a concern by asking the maintainer for a private contact channel through a minimal issue or an existing private conversation. Do not include private details in a public request. Reports will be handled as privately as practical and reviewed in context. Retaliation against someone reporting a concern is unacceptable.
