# Support

Start with [setup and troubleshooting](README.md), the [experiment protocol](EXPERIMENT.md), and [recorded results](RESULTS.md). You can read the evidence without downloading models. Tests and the saved-evidence audit also run without Ollama.

For reproducible bugs, use the [bug report form](https://github.com/dharmendrathinks/local-rag-reliability-lab/issues/new?template=bug_report.yml). For questions or feature suggestions, [open an issue](https://github.com/dharmendrathinks/local-rag-reliability-lab/issues/new/choose). Include your commit, OS, Python/uv/Ollama versions, exact command, expected behavior, and actual error. Use fictional data and remove private paths, document text, and credentials from logs before sharing.

Support is community based and best effort. This educational project offers no service-level agreement. Report vulnerabilities privately using [SECURITY.md](SECURITY.md).
